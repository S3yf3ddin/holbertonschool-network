
# holbertonschool-network

A collection of networking projects completed as part of the Holberton School curriculum. The repository covers fundamental networking concepts and practical Bash scripting exercises.

## Projects

| Directory | Description |
|-----------|-------------|
| [basics_0](./basics_0) | OSI model, network types, MAC & IP addresses, TCP/UDP concepts, port scanning, and host connectivity |
| [basics_1](./basics_1) | Configuring host IP entries, displaying active IPs, and port listening on localhost |
