
# 🌐 holbertonschool-network

> Networking fundamentals projects from the **Holberton School** curriculum — covering OSI model theory, TCP/UDP protocols, IP addressing, and practical Bash scripting for network configuration and diagnostics.

## 📁 Repository Structure

```

│   ├── 1-types_of_network
```

## 🛠️ Technologies & Tools

- **Shell:** Bash (`#!/usr/bin/env bash`)
- **Networking utilities:** `netstat`, `ping`, `ifconfig`, `nc` (netcat)
- **OS:** Ubuntu / Linux

---

## 🚀 Getting Started

Clone the repository and make scripts executable:

```bash
git clone https://github.com/S3yf3ddin/holbertonschool-network.git
cd holbertonschool-network
chmod +x basics_0/* basics_1/*
```
